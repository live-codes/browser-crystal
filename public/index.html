Everything below happens in this tab: the Crystal compiler, the linker and the program are all WebAssembly, and the standard library is fetched as data — no server compiles anything and your code is never uploaded. The first run is slow: it fetches about 22 MB of compressed assets — the compiler is 12 MB of that, nearer 36 MB once inflated — and compiles them.
